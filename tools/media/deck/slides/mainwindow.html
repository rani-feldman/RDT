RDT user manual · Part 2: Operating from the GUI

Here’s the main window. At the top are the menus and the toolbar, with the connection fields, the profile button, the connect button, and run and stop for polling. A slim red error bar appears under the toolbar only when there’s an error. On the left, the target panel shows one card per MCU. The watch tabs are in the centre, the chart, console and memory view sit below, and the status bar shows the link and each MCU’s latest reply time.
