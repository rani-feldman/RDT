Read and write

Every line of read can be pasted into write

$ rdt -w bench.rdtw read main:motor

main:motor motor_t, 16 bytes at 0x20000000

main:motor.speed = 27.0084591 float

main:motor.target = 3000 float

main:motor.current_ma = -120 (0xFF88) int16_t

main:motor.mode = MODE_RUN (1) mode_t

$ rdt -w bench.rdtw write main:motor.target 2500 -y

main:motor.target = 2500 rpm (confirmed by read-back)

$ rdt -w bench.rdtw dump main 0x20000000 32

20000000 D9 37 AD 44 00 40 1C 45 88 FF 01 00 01 00 00 00 |.7.D.@.E........|

Also poke for raw bytes. Item scaling and write safety apply on the command line too.

RDT user manual · Part 3: Operating from the command line · output from the simulator

Read opens a struct or array to every field, one line each, so any line can be copied into a write command. Write takes one value, in the item’s units, and confirms it by reading it back. Dump shows memory as hex and ASCII, and poke writes raw bytes. A watched item’s scaling and write safety apply here too.
