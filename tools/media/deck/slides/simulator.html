Try it on the simulator

A simulated device stands in for the firmware

Two MCUs, main and motorctl, each with an example ELF, on TCP and UDP port 5025.

  1. Start the simulator
  2. Open the example workspace
  3. Press Connect (F5): the Motor tab starts to move

# terminal 1

python -m sim

# terminal 2

rdt-gui examples/sim_bench.rdtw

# or from the command line

rdt -w examples/sim_bench.rdtw watch

RDT user manual · Part 1: Before you start

You can try everything without hardware. The simulator is a device on your own PC, with two MCUs, main and motor control, each with an example ELF file, listening on TCP and UDP port 5025. Start it in one terminal, open the example workspace in the GUI, and press Connect or F5. The values in the Motor tab start to move. Everything in this tour was recorded against the simulator.
