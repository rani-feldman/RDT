RDT user manual · Part 3: Operating from the command line

For scripts, the exit code is zero on success and one when anything fails, with the reason on standard error. Send with expect returns eleven when the reply doesn’t match. For longer scripts, use the Python API that the command line and GUI are built on: open a target from a workspace, then read and write values by name.
