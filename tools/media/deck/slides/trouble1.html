RDT user manual · Part 4: Troubleshooting

When every read times out, the firmware doesn’t answer the read command as written, or the link settings are wrong: check the template and terminator, try the command in the console, or use Test read. Link down with the port still open means the device answered none of the last three reads, so check that the board is running. An unplugged COM port comes back by itself. A silent secondary MCU is retried every two seconds. And a refused reply means the firmware’s reply isn’t comma-separated hex words.
