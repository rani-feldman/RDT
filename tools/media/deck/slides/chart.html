Chart, statistics, CSV

A live scope for firmware values

  • Ctrl+G, the wave button, or drag to chart
  • Each trace in its MCU’s colour
  • Up to four Y axes, by unit
  • Pause, zoom, Fit Y, two cursors
  • Min, Max, Mean, Samples (Ctrl+T)
  • Log CSV (Ctrl+L), opens in Excel

RDT user manual · Part 2: Operating from the GUI

Press Scope to show the chart. Add values with control G, the hover wave button, or by dragging them onto the chart. Values from any MCU can share it, each in its MCU’s colour, on up to four Y axes. Pause freezes the view while data keeps coming. The mouse wheel zooms, and the cursors show values and the time between them. Control T adds minimum, maximum, mean and sample counts, and Log CSV writes one row per poll to a file that opens in Excel.
