SCPI profile

You tell RDT how your firmware spells read and write

[scpi]

read = "SERV:MEM:READ? {mcu},{addr},{len}"

write = "SERV:MEM:WRIT {mcu},{addr},{value},{size}"

align = 4

max_response = 1024

timeout_ms = 500

  • Addresses are 8-digit bare hex: 08000000
  • Replies are comma-separated 32-bit hex words
  • A failed command gets no reply, so it times out
  • Every write is confirmed by reading it back
  • RDT never sends *IDN? or SYST:ERR? by itself

RDT user manual · Part 1: Before you start

RDT has no built-in firmware commands. The SCPI profile says how your firmware spells a memory read and a memory write. Addresses are sent as eight-digit hex with no prefix, and a read reply is comma-separated thirty-two-bit words in hex. A failed command gets no reply at all, so RDT sees it as a timeout, and it confirms every write by reading it back. RDT sends nothing else on its own: no identity query and no error query.
