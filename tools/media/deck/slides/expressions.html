RDT user manual · Part 1: Before you start

A device has one or more MCUs. MCU zero is the main one: it owns the link and passes requests on to the others. Each MCU has a name and its own ELF file. When you name something to read or write, the expression always starts with the MCU’s name. It can be a global variable, a struct member, an array cell, a pointer to follow, a file-static variable, or a raw address read as any type.
