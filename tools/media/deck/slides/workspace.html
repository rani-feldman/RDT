What you need to know

A workspace keeps everything about one bench

FileHolds
bench.rdtwConnection, MCUs and ELF files, polling, read-only default
bench.profile.tomlThe SCPI profile
bench.memory.tomlThe memory map: ranges besides the ELF sections
bench.watch.tomlThe watch tabs and the chart
bench.commands.tomlThe device’s known SCPI commands, for the console

The GUI and the CLI read and write the same files.

RDT user manual · Part 1: Before you start

Everything about one bench lives in a workspace. That’s a dot R D T W file, plus up to four files beside it: the SCPI profile, the memory map, the watch tabs and chart, and the device’s known commands for the console. The GUI and the command line read and write the same files.
