RDT user manual · Introduction

You can operate RDT in two ways. The GUI, R D T gui, gives you watch tabs, a live chart, a memory view and an SCPI console. The command line, R D T, does every device operation as a one-shot command, for scripts and quick checks. Both work on the same workspace files, so you can switch between them at any time.
