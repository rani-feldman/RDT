SCPI console

A terminal to the firmware

  • TX, RX, ERR and SYS lines with times
  • Suggestions from history and known commands
  • Commands list by group, with a filter
  • Find, log to file, send break, hex and text
  • Works while polling runs

RDT user manual · Part 2: Operating from the GUI

The console is a terminal to the firmware. Each line has its time and a tag: sent, reply, error, or RDT’s own notes. Type a command on the prompt line and press Enter. A query waits for its reply, and a failed command shows no reply. As you type, matching commands from your history and the known commands appear, with the best match in grey. The Commands list groups the known commands, and you can search the transcript, log it to a file, or send a break on a COM port.
