RDT user manual · Part 1: Before you start

To install, download the RDT setup from the releases page and run it. It installs for your Windows user only, with no admin rights, and everything RDT needs, Python and every package, comes with it. Setup can add the command line to your path, and workspace files open in RDT on a double-click. There’s also a portable zip you can unzip and run anywhere. You get three programs: the window, the command line, and the simulated device.
