Set up a bench

Once per bench, then save

  1. File > New workspace, or open one
  2. Pick the link: serial, tcp or udp
  3. Set the SCPI profile (gear icon)
  4. Add the MCUs and their ELF files
  5. Import the memory map
  6. Import known commands (optional)
  7. File > Save as

Target > MCUs and ELF files: id, name, short name, colour, ELF and timeout

RDT user manual · Part 2: Operating from the GUI

You set up a bench once, then save it. Start a new workspace or open one. Pick the link: a COM port and baud rate, or an IP address and port. Set the SCPI profile. Then add the MCUs: each row has an id, a name, a short name and a colour for its tag, its ELF file, and an optional timeout. Import the memory map and, if you like, the device’s known commands. Then save the workspace.
