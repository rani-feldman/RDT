You decide how often each value is read

▶ RUN

RUN / STOP (F7)

Stops or starts all polling. The global interval sits next to it, 500 ms by default.

Poll now (F6)

Reads every watched item once, in every tab, whether polling runs or not.

Merged reads

Nearby items on one MCU come in one command, from the same moment.

RDT user manual · Part 2: Operating from the GUI

Polling is under your control. The run and stop key, F7, stops or starts all polling, and the global interval sits next to it. Poll now, F6, reads every watched item once. Items close together on the same MCU are read in one command, so they come from the same moment. On a slow link, items fall behind instead of queueing, and the rate column shows what each one actually gets.
