What RDT does

From a variable’s name to its live value, over the product’s own link

Your link

A COM port, or LAN with TCP or UDP. No JTAG or SWD probe.

Your commands

RDT speaks the SCPI read and write commands you define.

Your ELF

Each MCU’s ELF turns a name into an address and a type.

RDT user manual · Introduction

RDT needs three things from you. First, the link: a COM port, or LAN with TCP or UDP. Second, the commands: RDT has no built-in firmware commands, it speaks the SCPI read and write commands you define. Third, the ELF file of each MCU, which turns a variable’s name into an address and a type.
