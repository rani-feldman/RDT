Edit a workspace

Build a bench from a script, no device needed

rdt --serial COM3 --profile fw.toml --mcu main=0:main.elf init bench.rdtw

rdt -w bench.rdtw add main:motor.speed --tab Motor --unit rpm --poll 100

rdt -w bench.rdtw add main:motor.target --min 0 --max 3000 --confirm

rdt -w bench.rdtw add main:motor.mode --read-only

rdt -w bench.rdtw tab add Tuning

rdt -w bench.rdtw memory import h7.memory.toml

rdt -w bench.rdtw commands import gac.csv

The same import and export as the GUI: memory, watchlist, commands. Plus rdt ui show and rdt history.

RDT user manual · Part 3: Operating from the command line

You can build and edit a workspace from the command line, with no device. Init saves a new workspace. Add puts an item in a tab, with its unit, polling, limits and write safety. Tab adds, renames or removes tabs, and memory, watch list and commands import and export the same parts as the GUI.
