RDT user manual · Part 4: Troubleshooting

RDT also refuses access on purpose. An ELF mismatch means the device runs another build: load the matching ELF or flash the matching firmware. Outside known memory means the address is in no ELF section or listed range. Read-only comes from the item, the workspace default, or a code section. And not confirmed means the value read back differs from the one written. Add only memory the firmware can read safely, and keep register blocks as peripherals.
