RDT user manual · Part 2: Operating from the GUI

The profile editor holds the read and write templates and the other settings. It shows each command exactly as it will be sent, and refuses a template that can’t work. While connected, Test read sends one read with the edited profile and shows the reply and the bytes it decodes to, before you apply it. Load from file fills the fields from a profile file.
