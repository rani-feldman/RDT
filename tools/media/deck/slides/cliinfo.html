RDT user manual · Part 3: Operating from the command line · output from the simulator

R D T info shows the link, the profile, and for each MCU its ELF check and memory map. This is real output from the simulator: both MCUs match their ELF files, and you can see each section and the peripheral range. Symbols and p type look things up in the ELF, with no device needed.
