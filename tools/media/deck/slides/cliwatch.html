watch rides through a lost link and an ELF rebuild. In rdt console, lines starting with a dot are RDT’s own: .read, .write, .history, .quit.

RDT user manual · Part 3: Operating from the command line · output from the simulator

Watch prints one line per sample until you stop it, and with dash dash C S V it also logs to a file. It keeps running through a lost link and reconnects on its own, and it reloads a rebuilt ELF. Send sends one SCPI command, and a query waits for its reply. Console opens the same interactive console as the GUI, with RDT’s own dot commands to read, write and recall history.
