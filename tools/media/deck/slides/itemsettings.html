Show raw values in real units

  • Format: dec, hex, bin or char
  • Fixed point (Q15, Q31, Q3.12), scale, offset and unit
  • Polling: global, manual, or its own time
  • Write safety: read-only, minimum, maximum, ask first

shown = raw / 2^q × scale + offset

RDT user manual · Part 2: Operating from the GUI

Right-click a watched item for its settings. You can choose its number format, and turn a raw value into real units with a fixed-point format, a scale, an offset and a unit. Each item can follow the global polling interval, have its own, or be manual. And write safety: make it read-only, set a minimum and a maximum, or ask before every write.
