User manual

Read, watch, chart and change firmware variables and memory over the device’s own COM port or LAN link, with no debug probe.

Remote Debugger Tool · Windows app and command line · one ELF per MCU · SCPI over COM, TCP or UDP

Welcome to RDT, the Remote Debugger Tool. This tour follows the RDT user manual from start to finish. RDT reads and writes the variables and memory of firmware while it runs, over the link the product already has: a COM port, or a LAN connection with TCP or UDP. You don’t need a JTAG or SWD probe, and the core is never halted.
