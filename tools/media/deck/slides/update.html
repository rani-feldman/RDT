Upgrade

RDT tells you when a new version is out

  • Checks GitHub once a day, with no sign-in
  • Shows what changed, with a Download button
  • Run the newer setup: settings and workspaces are kept
  • Help > Release notes lists every version

RDT user manual · Part 1: Before you start

Upgrading is simple. RDT checks GitHub once a day and says in the status bar when a newer version is out. The first time, a window lists what changed, with a download button. Run the newer setup: it closes RDT, replaces the old version, and keeps your settings and workspaces. Help, Release notes, shows the changes in every version.
