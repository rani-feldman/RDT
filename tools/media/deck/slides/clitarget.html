RDT user manual · Part 3: Operating from the command line

Every command that talks to the device needs a workspace or a target file. Give it with dash w, or RDT uses r d t dot toml from the current folder, or from your local app data folder. Options override the file for that run only: a COM port or a LAN address, another profile, a timeout, or the MCUs. Allow mismatch is the only way to use an MCU whose ELF doesn’t match. Dash v v logs every command and reply.
