Memory view

Raw memory, in the format you need

  • Pick the MCU, an address or a variable, a length
  • Refresh reads again at the polling interval
  • Right-click: signed or unsigned, 8 to 32 bits, ASCII, float, double
  • Double-click a cell to write it

RDT user manual · Part 2: Operating from the GUI

The memory view shows raw memory. Choose the MCU, type an address or a variable name, set the length, and press Read. Tick Refresh to keep reading. Right-click the dump to show cells as signed or unsigned chars, shorts, ints or longs, in hex or decimal, or as ASCII, float or double. Double-click a cell to write a new value. As everywhere else, access outside known memory is refused.
