Change a value

Edit in place, confirmed by read-back

  1. Double-click the value
  2. Type it in the item’s units, or an enum name
  3. Press Enter: RDT writes and reads it back

Refused when read-only, out of limits, or the ELF does not match.

RDT user manual · Part 2: Operating from the GUI

To change a value, double-click it, type the new value in the item’s units, and press Enter. Here, the motor target is set to twenty-five hundred r p m. RDT writes it and reads it back to confirm, and the status bar says so. Enums take their names, and integers take decimal, hex or binary. The write is refused, with the reason, when the item is read-only, the value is outside its limits, or the MCU’s ELF doesn’t match.
